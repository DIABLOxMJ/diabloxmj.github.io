Uberbukkit

Uberbukkit permet d'exécuter la plupart des plugins b1.7.3 sur les versions bêta antérieures. Compatible actuellement avec les versions b1.0 à b1.7.3.

Signalez tout bug que vous rencontrez sur notre serveur Discord (lien ci-dessus).

NetherMP

NetherMP est un mod de serveur a1.2.1_01 (a0.2.3) qui active la dimension Nether dans le multijoueur vanilla.

N'est plus pris en charge !

Version miroir

Version miroir télécharge toutes les versions de Java Edition depuis les serveurs de Mojang et vérifie les mises à jour. Protection contre le rechargement.

Attention : utilisation du processeur extrêmement élevée dans les versions v1.x, ce problème sera corrigé dans la v2.
