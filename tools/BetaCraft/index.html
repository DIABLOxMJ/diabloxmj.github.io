Notre objectif est de rendre le jeu et le plaisir des anciennes versions de Minecraft plus faciles, sur les consoles modernes comme rétro ! Découvrez nos offres ci-dessous.


Betacraft Launcher

Le projet principal de Betacraft est Betacraft Launcher, compatible avec toutes les versions de Minecraft antérieures à la 1.6 encore existantes. Il permet d'y accéder facilement. (Une grande partie de ces versions proviennent de Omniarchive, alors n'hésitez pas à y faire un tour !)

Le lanceur corrige divers plantages du jeu, l'absence de son et de skins de personnages, et bien plus encore. Un résumé complet des correctifs est disponible sur le GitHub.

Si vous possédez un serveur Minecraft, vous devez faire une demande de vérification pour qu'il apparaisse dans le lanceur. Contactez-nous via nos réseaux sociaux (Discord ou Bluesky) pour obtenir une clé privée, puis suivez les instructions ici pour rendre votre serveur visible !

La liste des serveurs est également disponible dans le navigateur, ici.

Nous développons également un successeur à notre lanceur v1 : Betacraft Launcher v2, plus abouti et intuitif, plus stable, compatible avec la quasi-totalité des versions de Minecraft et (presque) avec toutes les plateformes existantes !

Téléchargements sont disponibles ici.

Si vous préférez utiliser un autre lanceur, envisagez d'utiliser LegacyFix un autre projet de notre initiative qui corrige les anciennes versions, ou applique les Betacraft Proxy pour des correctifs limités, comme la correction de l'interface, du son et de l'authentification.

Communication

Rejoindre le serveur

Adresse du serveur : betacraft.fr

Pour rejoindre le serveur, vous devez posséder une licence Minecraft Java Edition et un correctif d'authentification. Si vous utilisez le Launcher Betacraft ou un Proxy Betacraft, vous devriez pouvoir vous connecter sans problème !

Si vous préférez ne pas utiliser ces outils, vous pouvez vous procurer un logiciel comme…

SimpleOnlineModeFix (jarmod) ou RetroAuth (Fabric mod) pour votre instance Minecraft.


Uberbukkit

Uberbukkit est un logiciel serveur Minecraft (basé sur Project Poseidon) offrant la compatibilité avec les plugins b1.7.3 pour les anciens protocoles bêta (b1.0 à b1.6.6) et les correctifs d'exploits.

Il vous suffit de télécharger Uberbukkit, de configurer votre version cible et vos mécanismes de jeu en modifiant le fichier uberbukkit.yml, et tout devrait fonctionner.
