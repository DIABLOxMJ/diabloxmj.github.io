Se connecter

Pour obtenir un code d'accès, utilisez Minecraft 1.5.2 pour vous connecter au serveur.

Assurez-vous de vous connecter au préalable à votre compte Microsoft avec une licence Minecraft Java Edition achetée.
Les jeux piratés ne sont pas pris en charge.

Les codes ne sont pas sensibles à la casse.
Vous pouvez également omettre le tiret (-)

En vous connectant, vous pouvez personnaliser l'apparence et la cape sur le proxy Betacraft.

C'est pratique si vous souhaitez conserver votre apparence détaillée pour les versions modernes et une apparence plus simple (mais compatible) pour les anciennes versions.

Vous pouvez également réinitialiser le cache de votre apparence au lieu d'attendre 7 jours pour sa mise à jour (super !).
